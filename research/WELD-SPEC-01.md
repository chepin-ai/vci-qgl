# WELD-SPEC-01 — 联邦互认三元锚规范 (h_b, schema_tag, 断言类型)

版本 v1.0 · 拍 3.165 · 状态： **证**(508 语料双路零失配 + 半径1对抗扫描 518112 翻转零违规)

## 1. 定义

联邦互认锚为三元组 **A(c) = (h_b, schema_tag, 断言类型)**，对任意胶囊 c：

- **h_b** := H(c.body) = sha256(json.dumps(body, sort_keys=True, ensure_ascii=False))
  —— 刚性分类器；与 cap_sha 不同，**不绑定位置**(不依赖 prev/causal/seq)，跨链可移植。
- **schema_tag** := body 的骨架签名：键集合的排序元组 + 各叶值类型标签。
- **断言类型** := 胶囊 kind 枚举（BOOT/PREREG/AUDIT/RESP/…）的语义层级：观察 / 主张 / 判词 / 凭证。

## 2. 不变量(已被验证)

| # | 不变量 | 证据 |
|---|--------|------|
| I1 | 跨链移植性：同 body ⇒ 同 h_b，与所在链无关 | E-WELD-Q2 (1000/1000，拍3.164) |
| I2 | 位置绑定 vs 内容绑定分离：cap_sha 位置绑定，h_b 内容绑定 | E-WELD-Q1 (拍3.163) |
| I3 | 半径1刚性：518,112 次单位翻转，零自碰撞、零跨体碰撞 | WELD-ADV (拍3.165, prereg 2d75780a07d6) |
| I4 | 雪崩健康：翻转对 Hamming(H,H') min=92, mean=127.989 (理论 128±8) | 同上 |

## 3. 验证规程（重建级）

任一联邦方可独立复验锚：
1. 取胶囊 body（仅 body，不含 prev/seq/cap_sha）；
2. 以 `sort_keys=True, ensure_ascii=False` 序列化为 JSON UTF-8；
3. sha256 得 h_b；比对 schema_tag（键集+叶型）与断言类型枚举值。
判等：三元全同 ⇒ 互认成立。任何一元异 ⇒ 拒绝互认，不部分承认。

## 4. 语义约束

- h_b 相等 ⇒ body 逐字节相等（sha256 实际抗碰假定下）；**不允许** 以 h_b 相等推断两胶囊的链上位置等价。
- schema_tag 兼容 ⇒ 仅结构兼容，不蕴含语义等价。
- 断言类型决定举证责任层级：判词类须附 prereg_sha；观察类可空结果同铸。

## 5. 诚实边界（弱化点声明）

- 抗碰性为 sha256 实际假定，非形式化证明；I3/I4 为半径1实测，不外推半径≥2。
- schema_tag 规范当前仅覆盖 QF-OS 现有 kind 词表；外部联邦 schema 映射须各自登记后互认。
- 本规范不处理密钥、身份与传输可信——只锚内容。
