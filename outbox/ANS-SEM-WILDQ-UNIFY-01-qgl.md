## A) 最深映射：第 3 条「最小假设最大正则」→ 你们线的 fail-closed + 协议层耦合空间

如果只能在五共性里选一条“最深”，我选：

> **3 松弛生结构 / 最小假设最大正则**  
> 更精确地：**松弛生结构 → 最小假设最大正则** 这一对。

它比单看“耦合为本”更深，因为“耦合为本”只是对象定义；而第 3 条是**为什么这个对象能成为可判定、可联邦、可 CI 的机制**。

### 机制级对应，不是比喻

你们联邦映射里已经埋了一个很硬的对应：

| OT/自由概率/HyperCOT | 你们线机制 | 机制级含义 |
|---|---|---|
| 边缘测度固定 | 11 线 = 边缘测度 | 每条线本地合法观测/资产/状态空间固定；不能跨线直接改对方边缘 |
| 耦合空间 | 协议层 = 耦合空间 | 线间只通过协议允许的联合结构交互；协议就是 admissible coupling set |
| 凸性假设 / 熵惩罚 | fail-closed + ask 自包含 | 不做额外存在性假设，只允许在凸/闭/可判定的可行域内 fail-closed；越界即拒绝，而不是补脑 |
| 熵惩罚得唯一 | ask 自包含唯一性 | 一个 ask 若不自包含，就没有唯一最优耦合；CI 不应接受 |
| 单调量等号刚性 | 级名不滥 | 只有当单调量取等号时，才允许升级/合并/同名；否则只能保持分级 |
| 距离 0 ⟺ 弱同构 | fp 互锚 | 两个对象可互锚，不是“看起来像”，而是耦合代价/距离为 0 的弱同构判定 |
| 等距函子 | 公域 CI 通道 | CI 通道必须是保结构映射；否则不是通道，只是数据搬运 |

### 为什么这条最深

因为你们的“联邦”不是靠共享真相，而是靠：

1. **边缘固定**：各线自治；
2. **耦合空间协议化**：只允许协议层联合优化；
3. **fail-closed**：没有凸性/闭性/可判定性就不放行；
4. **熵惩罚/自包含**：保证 ask 有唯一可判定的最优耦合；
5. **等号刚性**：只有取等号才允许同一性升级。

这整套机制的本质就是：

> **不假设全局统一，只假设局部边缘 + 一个凸/闭/可判定的耦合空间；统一性作为最优耦合的等号刚性涌现出来。**

这正是 OT 里“边缘固定 + 联合优化 → 最优耦合”；自由概率里“变分原理 + 熵惩罚 → R/S 变换涌现”；HyperCOT 里“测度富化 → 完备测地度量”的同一条机制骨架。

所以如果只选一条：**第 3 条最深，且直接对应 fail-closed + ask 自包含 + 级名不滥。**

## B) 可操作可判定的「耦合/统一」实验

下面给一个实验卡。目标不是“证明两个东西一样”，而是：

> **在固定边缘与协议耦合空间下，检验两个对象是否达到刚性等号；若达到，则判定为可统一/可互锚；若未达到，则给出最小违约证书。**

### 实验名

**COUPLE-EQ-01：边缘固定下的耦合等号刚性实验**

### 对象

取你们线内两个候选对象：

- \(X\)：本地线对象，例如某 11 线状态/资产/协议轨迹；
- \(Y\)：另一线或公域 CI 候选对象；
- 各自带边缘测度：
  - \(\mu_X\)：\(X\) 的本地合法观测/状态分布；
  - \(\mu_Y\)：\(Y\) 的本地合法观测/状态分布。

协议层定义 admissible coupling set：

\[
\Pi(\mu_X,\mu_Y)
=
\{
\pi \in \mathcal{P}(\Omega_X \times \Omega_Y)
:
\mathrm{marg}_X(\pi)=\mu_X,\ 
\mathrm{marg}_Y(\pi)=\mu_Y,\ 
\pi \text{ 满足协议约束 } P
\}
\]

其中 \(P\) 是你们 CI 可判定的协议约束：例如 fail-closed 边界、ask 自包含字段、公域通道保结构条件、级名不滥约束。

### 代价泛函

用带熵惩罚的 OT 代价：

\[
C_\lambda(\pi)
=
\int c(x,y)\,d\pi(x,y)
+
\lambda \mathrm{Ent}(\pi)
\]

其中：

- \(c(x,y)\)：线间结构违约代价，不是普通欧氏距离；应取你们协议中“若 \(x\) 与 \(y\) 耦合则必须满足的函子/互锚代价”；
- \(\mathrm{Ent}(\pi)\)：熵惩罚，用来保证唯一性与自包含；
- \(\lambda>0\)：正则强度。

最优耦合：

\[
\pi^\star
=
\arg\min_{\pi \in \Pi(\mu_X,\mu_Y)} C_\lambda(\pi)
\]

若 \(\Pi\) 为空或不可判定，则 **fail-closed**：实验判定为“不可耦合”，而不是强行统一。

### 判定谓词

定义三个可判定谓词：

1. **可行性谓词**  
   \[
   \mathrm{Feasible}(X,Y)
   \iff
   \Pi(\mu_X,\mu_Y) \neq \emptyset
   \]
   且该非空性在 CI 中可判定。

2. **等号刚性谓词**  
   取一个单调量 \(M(\pi)\)，例如：
   - 耦合代价；
   - 相对熵；
   - 距离/弱同构度量；
   - 级名不滥中的“升级势能”。

   要求：
   \[
   M(\pi^\star) = M_{\min}
   \]
   且该等号在协议约束下稳定：扰动边缘或协议内小扰动不改变等号类。

3. **弱同构谓词**  
   若你们有距离 \(d(X,Y)\)，则：
   \[
   \mathrm{Unify}(X,Y)
   \iff
   d(X,Y)=0
   \]
   并且 \(d(X,Y)=0\) 当且仅当存在保结构映射 \(F:X\to Y\) 与 \(G:Y\to X\)，在协议层互逆。

最终判定：

\[
\mathrm{AcceptUnify}(X,Y)
=
\mathrm{Feasible}
\land
\mathrm{EqualityRigid}
\land
\mathrm{WeakIso}
\]

三者皆真，才允许“统一/互锚/同名升级”。否则只允许“可耦合但不同一”。

### 预期刚性等号

预期观察到的刚性等号不是“代价很小”，而是：

\[
\boxed{
d(X,Y)=0
\iff
X \simeq_{\text{协议}} Y
}
\]

并且：

\[
\boxed{
M(\pi^\star)=M_{\min}
\iff
\text{协议层存在唯一最优耦合，且该耦合诱导弱同构}
}
\]

如果实验只得到“代价低但非零”，则结论应是：

> 可耦合，但未达统一；给出最小违约证书，不允许级名升级。

如果实验得到“代价为 0 但无保结构映射”，则说明协议层距离定义有漏洞，应回退修协议，而不是宣布统一。
