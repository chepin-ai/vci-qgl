## 0. 口径校准（否则 M1 会被误读）

枢案写"M 沿波次非增"，但 M 是**代价型量**（越刚性越小，刚性态 M=0）。所以：

- **M1 的正确读法**：波次推进使 M 单调**非增**（M↓ 是好方向），等号 M_line=0 是刚性升级门槛。
- 这不是"熵增"式单调，而是**收敛到 0 的 Lyapunov 型单调**。这层读法必须先立，否则 M3"M 严格增⇒非收尾波"就成了同义反复。

## 1. 对枢案 M 的结构诊断

M(W) = α|undecided| + β|fail-open| + γ|未闭环FINDING| + δ|无fp卡件| + ε|非自包含ask|

**优点**：五项都是"可数事件"，避免连续量带来的权标定不可复现；M_line=0 ⟺ 五类归零，是清晰的刚性判据。

**结构性缺陷**（这是 B 的核心）：

1. **M 是"缺陷计数和"，不是"闭合度度量"**。它只能判"有没有病"，不能判"是否已到刚性态"。刚性要求的是**对所有活跃问句的判定闭合**，而 M 只统计了若干缺陷类。存在 **M=0 但不可升级**的构型（见 B-1）。
2. **δ 项口径可疑**：|无fp卡件| 的绝对值没有上限标定，且"无 fp"本身不是缺陷——fp 是**追溯键**，不是每件都必须有。这一项应改为"|活跃标定无 fp 关联|"，否则 δ 会与 γ 部分重叠。
3. **缺"跨线一致性"项**：M 是**线-local 求和**，但联邦刚性需要**跨线 fp 对齐**。单线全 0 不能推出联邦 0（见 B-2）。
4. **缺"时间/波次标签"项**：undecided 若无 staleness 权重，一个刚产生的 undecided 和一个跨 5 波的 undecided 等价——这会让 M1 的"负结果入册⇒闭环只增不减"假设在**新开波次**时被打破。

## 2. A) 线-local 单调量 M_line

**A-1 参数选择**：本线取 M_line 沿**波次序号 n** 单调，但按"每波净闭环数"参数化更稳：

```
M_line(n) = D(n) + F(n) + U(n)
  D = 本线 undecided/悬置 ask 数（带 staleness 权重 w=1+log(1+age_in_waves)）
  F = 未闭环 FINDING 数
  U = 未挂 fp 的活跃标定数
```

**A-2 等号集**：

- M_line = 0 的**充分条件**：本线所有活跃 ask 均已判定（含"判为 undecided 且已挂 fp 归档"）、所有 FINDING 已闭环、所有活跃标定已挂 fp。
- M_line = 0 的**必要条件**（弱于枢案）：不存在"活跃且未归档"的缺陷类。
- 关键区别：**"判为 undecided 并归档"在 M_line 中计 0，在枢案 M 中计 α>0**。这是两案最实质的分歧点。

**A-3 与枢案 M 的关系**：

- **子项关系（部分）**：M_line 的 D、F 两项在忽略 staleness 权重时，分别是枢案 α、γ 的线-local 投影。
- **独立项**：M_line 不含 β（fail-open）、ε（非自包含 ask）——这两项本线视为**波级治理量**，不归线-local。
- **反例关系（关键）**：存在构型使 **M_line=0 而 M>0**：本线全闭环，但联邦级有 fail-open 事件挂在别的线。这不是矛盾，是层次差——**M_line 与 M 是不同层级的度量，不可互推**。
- **反向**：存在 **M=0 而 M_line>0** 若枢案把"归档 undecided"计入 0 而本线计 staleness>0。这就是口径分歧点，需要在联邦层裁定"归档 undecided 算不算闭环"。

**A-4 本线结论**：M_line 沿波次**非增**成立，但等号集比枢案宽——**"已归档的 undecided"在本线计入闭环**。若联邦采纳枢案口径（undecided 恒计 α>0），则本线 M_line 是枢案 M 的**下界**，不是子项。

## 3. B) 对枢案 M 的反例与修正

**B-1 反例：M=0 但不可升级**

构型：某线所有活跃 ask 均已有判定、FINDING 全闭环、fp 全挂、无 fail-open、无自包含违规 → **M=0**。但该线的关键判定**互相矛盾**（例如 ask-7 判 A，ask-12 判 ¬A，两者都"已归档"）。枢案 M 无"互斥判定"项，判 M=0，但**不可升级刚性**，因为刚性态的语义是"判定一致可升级"，不是"缺陷计数归零"。

→ **M 缺一项：|互斥判定对|（contradiction pairs）**。记为 ζ 项。加 ζ 后，B-1 被覆盖。

**B-2 反例：M>0 但已刚性**

构型：联邦已宣布刚性态，但历史上遗留 3 个 undecided 已归档、1 个 fp 缺失但已挂"豁免标定"。按枢案口径 α|undecided|>0 ⇒ M>0，但实际已刚性。

→ 这说明 **M 应是"活跃未归档缺陷"计数，不是"历史缺陷"计数**。修正：所有五项加**活跃性谓词** act(·)，M = Σ w_i · |act(缺陷_i)|。已归档/已豁免的不计。

**B-3 缺失项清单（修正建议）**

| 项 | 含义 | 为何必需 |
|---|---|---|
| act(·) 谓词 | 只计活跃缺陷 | 否则 M 不沿波次非增（归档不减 M） |
| ζ 互斥判定对 | 逻辑一致性 | 否则 M=0 不蕴含可升级 |
| ξ 跨线 fp 对齐缺口 | 联邦级一致性 | 否则线-local 0 不能合成联邦 0 |
| staleness 权重 | undecided 老化 | 否则新 undecided 与陈 undecided 等价，M1 在新开波次失效 |

**B-4 修正后的 M1 重述**

> 若每波 (i) 只增闭环、(ii) 新 undecided 带 staleness 权重、(iii) 五项均加 act 谓词，则 M_v2 沿波次**非增**，且 M_v2=0 ⟺ 可升级刚性态（在 ζ、ξ 亦为 0 时）。

**B-5 对 M2 的修正**

枢案 M2："M_line=0 ⟺ 可升级刚性；级名不滥闸门 = M_line=0 且双轮评审"。加 ζ、ξ 后，M2 的等号集**收窄**——原 M2 的 ⟸ 方向（M_line=0 ⇒ 可升级）在 B-1 反例下**不成立**，必须补 ζ=0。建议 M2 改为：

> M_line=0 ∧ ζ=0 ∧ ξ=0 ⟺ 可升级刚性态（双轮律仍为并行必要条件）
