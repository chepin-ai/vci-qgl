## ③ Lean 锚 Prop 定义形（零 sorry 诚实锚）是否满足锚定纪律

**裁定：满足，且是 EXT 系列锚定纪律的一个范式升级。**

- 锚定纪律的传统形态是**定理形锚**（`theorem capAnchor : ∃! u, ...`），其风险是：若证不出，Lean 文件会以 sorry 收场，锚即失真。
- 本帧采用 **Prop 定义形锚**：
  ```
  Prop := ∃! u ∈ capBox z r, capF P u = 0
  ```
  配合 `capF_p1_eq_vf` 焊缝机证（把 `capF P` 与 Lean 核 `vf` 逐字对齐），实现：
  - **零 sorry 零 axiom**：Prop 本身不承诺真值，只承诺**语义**；
  - **build rc=0**：锚可编译，即锚**语法与类型层成立**；
  - **外证层 DONE / 内核层 BLOCKED(B1) 明码**：证明义务被显式登记为未完成，而非用 sorry 掩盖。
- 这正是锚定纪律的**诚实形态**：锚的职责是**固定命题语义与接口**，而非**冒充已证**。Prop 定义形 + 焊缝机证 + 内核 BLOCKED 明码，三者组合构成**"可编译的诚实锚"**——比一个 sorry 的 theorem 形锚**更符合纪律**。
- **唯一限定**：Prop 定义形锚的**赎回路径**必须明示——即 B1 BLOCKED 的解除条件是什么（例如"接入 RadiiPolynomial 四界+p(r)<0 的 Lean 化"或"接入 2610.02335 证书 Lean 化"）。**建议在 OBL-EXT10 中显式挂一条 B1 解除条件**，否则该 Prop 有长期悬空风险。

**结论**：**满足锚定纪律，且应作为后续 EXT 的锚形推荐模板**。

2. **赎回路径明确度**：B 的赎回物是"零点隔离见证 + 截断误差区间界"，**可核验、可双器复算**，与 WELD-A 的"缺口—见证—赎回"闭环**直接对接**。A 的赎回物（有限维下界）易落入"下界常数调优"的泥潭，**赎回判据模糊**。
3. **风险分布**：B 的核心风险是 ζ 零点计算的**区间可靠性**，已被 RadiiPolynomial/Arb 类工具充分工业化；A 的核心风险是**下界常数的可证最优性**，这是开放问题级风险。**同风险预算下 B 期望收益更高**。

**缓 A 而非弃 A**：A 的"计算复杂度有限维下界"若与 B 的"零点隔离"结合，可形成**"隔离难度→下界"的桥**，是中长期靶子。**建议 OBL-EXT10-a 记 B 为下一靶子，A 记为 OBL-EXT10-b 备选**。
