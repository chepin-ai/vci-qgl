## (a) 四范式碰撞图 — **pass（成立）**

- **P1 区间算术证书 / P2 SAT 证明证书 / P3 形式化证明助手 / P4 PINN 失败模式**四者的并列是**准确**的：它们分别落在「连续数值包络」「离散可判定搜索」「交互式类型论内核」「学习式近似求解器」四个正交信任生成机制上，碰撞面是“证书/见证的可机检性”而非“结论真值”。
- 与 **联邦级名体系/schema 机检/fp 互锚/退火路径** 的同构判定**方向正确**：
  - 名体系 ↔ 证书命名与义务声明（P1/P2/P3 各有其 witness schema）
  - schema 机检 ↔ 证书形状检查（drat-trim / coqchk / interval checker）
  - fp 互锚 ↔ 跨范式指纹指纹（同一命题在四范式下的等价锚）
  - 退火路径 ↔ 复杂度—信任度权衡曲线（P4 恰在此曲线的低信任端点）
- **限制**：同构目前是**结构同构**而非**保真同构**——P4 的“失败模式”并不产出证书，只产出反例分布与失配统计。建议在图中显式标注 P4 为 **“负证书/反见证”支路**，否则同构在 P4 顶点会被读作“PINN 也出证书”，属类别错误。

## (b) 镜像律候选 M4 / M5 / M6 — **M5 pass；M4 pass（带域限）；M6 pass（带前置条件）**

- **M4 延拓律（curriculum ≡ 退火 ≡ 同伦）**：入册合格，但需降为**“结构等价律”**而非“同一律”。三者共享“参数化路径 + 单调势降 + 极限对象不变”的骨架；但 curriculum 的学习动力学、退火的统计力学、同伦的类型论各自有独立的**不变量与收敛条件**（温度调度 vs 类型等价路径 vs 损失地貌）。建议入册时附“**限制条款**：仅在‘路径不变量保持’子范畴成立”。
- **M5 TCB 最小化律（求解器不可信 + 小型检查器 + 检查器须被检查）**：**直接入册，无条件通过**。这是 de Bruijn 准则的现代复述（LCF / de Bruijn criterion），在本联邦里由 P2/P3 实案支撑，且第三项“检查器须被检查”正是 (c) 的入口，逻辑自洽。
- **M6 审计锚律（内容寻址为第三方复核前置）**：入册合格，但**必须**写清“前置”是**必要非充分**——内容寻址保证的是“同一对象被复核”，不保证“对象本身可信”（哈希锁定 ≠ 语义正确）。建议正式化为：**不可篡改的复核基线**，而非“可信性来源”。

## (c) FM-015 候选（检查器缺检模式） — **pass，入 FM-LIB**

- drat-trim 接受恶意假证书是**教科书级实例**：它命中的不是“求解器错”，而是**“检查器的接受关系过宽 / 未覆盖某类反例”**——即 TCB 外沿的缺检模式（missing-check pattern），与 FM-LIB 的失败模式谱系正交（不同于求解器漏洞、不同于规格误译）。
- 建议补**两条元数据**再入册：
  1. **版本指纹**：drat-trim 的具体 commit（该模式已在后续修补中讨论）；
  2. **证明义务缺口**：指出被省检的是哪一条 RUP/RAT 侧条件，避免“检查器不可信”被泛化成口号。
- 与 M5 第三项（检查器须被检查）**互为实证—律条对**，建议在 FM-LIB 中做交叉引用。

## (d) 元问题 v2 + META-PIPE-01 — **pass（批准为联邦元结构，附实施条件）**

- **元问题 v2 四要件**（信任级的机检化 / 可申诉 / 域限 / 跨范式制度化授予—维持—降级—撤销）**覆盖完整**，且与 (a) 的四范式、(b) 的三律同构：机检化对应 schema 机检，可申诉对应 fp 互锚的争议仲裁，域限对应退火路径的适用域，授予/维持/降级/撤销对应名体系的**生命周期管理**。
- **META-PIPE-01 七阶段**（候选 → 框架伴生 → 双轮 → 域限正式 → 镜像锚定 → 证书化 → 对抗复核）**逻辑连贯**，其中“双轮”“对抗复核”是**必要**的，因为单轮流程无法处理 (c) 类检查器缺检——缺检只能由对抗轮暴露。

## (e) F-X1 区间证书实验 — **pass（效力认可，域限明确）**

- 6/6 PASS 的**关键**在于实验**自己限定了效力层**：外向舍入包络 |marg| ≤ 1.55e-11、cost 宽 1.32e-13、f64/f80 双包含 —— 这是**求值层**的包含性证明，不是**存在性层**的证明。
- **亚 LP 松弛由认证不可行性解释**：这一点尤其重要——它表明实验没有偷偷把“数值宽”当作“可行”，而是用**独立不可行性证书**解释亚松弛，这恰是 (a) 中 P1 与 P2 的**互锚实证**。
- **效力边界（必须写入结论）**：
  - 认可范围：**求值层区间包络的可机检证书**；
  - 不认可范围：**“存在性/最优性”陈述**、以及**超出 f80 外的精度外推**；
  - 双包含（f64/f80）是**必要条件**，非“跨架构已证”的充分证据——建议补一条**异架构复现**再升级效力等级。
